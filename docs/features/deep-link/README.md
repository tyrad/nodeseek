# NS Connect 分享菜单与 URL Scheme

在 iPhone 上下载所需的 `.shortcut` 文件，用系统「快捷指令」打开，点「添加快捷指令」。然后从其他 App 的分享菜单运行。三个模板均已签名。

| 模板 | 分享内容 | 打开后 |
| --- | --- | --- |
| [打开 NodeSeek 链接](./打开%20NodeSeek%20链接.shortcut) | Safari 网页或网址 | 取第一个网址，官方帖子和用户主页在原生页面打开，站外网页在 App 内的 Safari 浏览器打开 |
| [搜索选中文字](./搜索选中文字.shortcut) | 在 Safari、备忘录等支持分享所选文字的 App 里选中一段文字，点「分享」 | 将这段文字作为关键词，打开 NS Connect 并搜索帖子 |
| [预填 NodeSeek 帖子](./预填%20NodeSeek%20帖子.shortcut) | 文本或网址 | 快捷指令询问标题，将分享内容填入正文，由你核对并决定是否发布 |

## 可用地址

| 操作 | 示例 | 行为 |
| --- | --- | --- |
| 帖子 | `nsconnect://post/893437-1` | `893437` 是帖子 ID，`1` 是页码，省略页码也打开第一页 |
| 指定楼层 | `nsconnect://post/1016685-2?floor=18` | 打开第二页并定位第 18 楼 |
| 网页 | `nsconnect://open?url=https%3A%2F%2Fwww.nodeseek.com%2Fpost-893437-1` | 接受 HTTP(S)。`nodeseek.com` 和 `www.nodeseek.com` 的帖子及 `/space/<uid>` 进入原生页，其他官方路径忽略，其他域名交给 Safari 浏览控制器 |
| 用户主页 | `nsconnect://user/12345` | 按正整数 UID 打开原生资料页 |
| 搜索帖子 | `nsconnect://search?q=Swift` | 提交关键词。范围缺省、为 `post` 或无法识别时搜索帖子 |
| 搜索用户 | `nsconnect://search?q=Swift&scope=user` | 切到用户范围并提交；游客受站点搜索权限限制 |
| 预填帖子 | `nsconnect://compose?title=A%20%26%20B&body=Swift%0AiOS` | 标题、正文均可省略，分别最多 200、20,000 个字符。超过上限会忽略整个请求 |
| 探针 | `nsconnect://probe` | 打开探针列表。原有小组件生成的 `?instance=<UUID>&node=<节点标识>` 继续定位到对应节点 |

构造链接时对每个参数值单独做一次 URL 编码。例如正文里的换行写成 `%0A`，空格写成 `%20`，`&` 写成 `%26`，`#` 写成 `%23`。将完整网页地址传给 `open` 时，连同页内锚点一起编码。

阅读模式会打开搜索页。多 Tab 模式在底栏有搜索入口时选中该 Tab，底栏没有搜索入口时从当前页进入搜索。已在二级页面时，搜索保留返回原页的路径。同一页面上连续点按完全相同的地址，只跳转一次。离开后可再次打开。

发帖需要登录。游客会看到登录页，登录后可再次点开原链接。编辑器已有本机草稿时可恢复原稿或明确选择替换。另一个链接到达时，已打开的编辑器、登录页或浏览器会留在当前画面。
