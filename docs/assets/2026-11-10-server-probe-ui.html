服务器监控 · 第三版

「仪表」方向：大号主数字 + 等宽小字，用真实的 1 小时趋势线代替静态进度条。在第二版基础上给指标加系统色：CPU 蓝、内存靛、磁盘青、网络粉；框架仍是黑白。趋势线是测试面板 /api/records/load 的真实数据。

三个视觉锚点① 汇总区用反色卡片（浅色模式黑底，深色模式白底）；② CPU 用 36pt 粗数字配 1 小时趋势线；③ 内存和磁盘用 24 格刻度条，比连续进度条更有“仪表”感。
两种字体名称和主数字用 SF Pro；元信息、单位、时间用 SF Mono（大写，字距略放宽），营造技术感。不使用渐变和阴影。
离线 ≠ 拿不到数据离线时，趋势线在最后一次上报处打一个点，之后变成虚线，并显示红色「离线」。过期时显示时钟和「缓存 · X 前」，趋势线变灰，状态点隐藏。
指标色 + 告警每种指标固定一个系统色（CPU systemBlue、内存 systemIndigo、磁盘 systemTeal、网络 systemPink），App 和小组件保持一致。用量 ≥70% 时统一变为 systemOrange，≥90% 变为 systemRed。离线和缓存状态一律显示为灰色。
