# 删除旧版详情列表前的最终评估（2026-11-24）

目的：决定能否删除 Texture（ASTableNode + DTCoreText）详情列表，只保留 UICollectionView + TextKit。前一轮对比见 [2026-11-22](detail-textkit-vs-texture-2026-11-22.md)。

## 结论

可以删除 Texture 详情列表这条路径，但 DTCoreText 渲染器暂时不能一起删：

- 新版仍以它兜底。在 30 个线上帖子、61 页缓存里，518 个楼层有 2 个退回网页渲染（一楼没有 Markdown 原文，一楼图片地址为 `https://`），272 个签名有 2 个退回。
- Texture 节点还被个人主页内容列表、发帖预览、楼层预览等页面使用，不属于本次删除范围。

删除前建议先处理下文「尚未处理的差异」中的签名密度一项。

## 一、渲染差异

方法：登录状态下用同一构建、同一模拟器（iPhone 17 Pro，iOS 26.5），两种引擎各打开 30 个线上帖子，每帖截 6 屏，左右并排逐屏核对；可疑处读原图和站点 HTML 定位原因。另有离线回放 256 对楼层截图，高度差 ≤ 1 pt 的有 155 对。

本轮已修复（均有单元测试）：

| 现象 | 例子 | 原因 | 提交 |
|---|---|---|---|
| 二级列表被拍平成一级 | 1074764 主楼 | 渲染未区分嵌套层级 | `f2310c8` |
| 签名上方多一道分隔线 | 1075091 #3、1075050 #4 | 签名 HTML 以 `<hr>` 开头，旧版不显示开头的分隔线 | `c24f629` |
| 行内代码变成正文字号 | 1074978 #3 | 旧版样式表行内代码 13、正文 17 | `643c950` |
| 连续图片间多出约 60 pt 空白 | 1075030 主楼 | 图片切开段落后，切口处的换行成了空段 | `2df7342` |
| 不带协议的域名不是链接 | 832584 #83 | 网页 linkify 识别无协议域名；改为沿用本楼网页已生成的链接 | `8fc1697` |

尚未处理的差异：

| 现象 | 例子 | 说明 |
|---|---|---|
| 带签名的楼层高 5～12 pt | 普遍 | 正文到签名、签名行距、签名到操作栏都比旧版大；长帖累积明显，是否收紧需定 |
| 连续空格被保留 | 1074764 #13 | 网页折叠为一个空格，新版原样保留 |
| 引用框内文字贴右边 | 1067722 #11 | 「编辑于 …」紧贴引用框右缘 |
| 相邻引用合成一块 | 893437 主楼 | 旧版两块灰底中间有间隔 |

新版更好的地方：引用中的代码块显示为引用；引用框占满宽度；正文可选字。

## 二、分页

模拟器 E2E 全部通过：`thread-pagination`（Texture）、`textkit-pagination`、`textkit-backscroll`、`textkit-paging-timing`。`textkit-paging-timing` 实测追加、刷新、重试后的位置偏移均为 0，请求序列 1、2 无重复。

本轮及上一轮修复：只看 TA 自动补页失败后无法继续加载（`502d153`）；主楼点赞或风险提示刷新整表重排（`0efa9e5`）；切后台再回来整页重排（`833f690`）。

仍未覆盖的风险（代码审查发现，未复现）：

1. 字号、签名开关、登录状态变化触发 `invalidate` 时清空高度，不恢复阅读位置。
2. 行尚在排队时按锚点定位，可能落到错误的行。
3. 从其他页面返回时不检查是否需要预取下一页。
4. `userScrollInProgress` 在个别手势路径下可能不复位。
5. 页脚固定 56 pt，大字号下可能截断。
6. 向上滚入尚未测量、之后才加载图片或签名的楼层时可能跳动；合成纯文字楼层两种引擎都未复现。

旧版的结构优势是插入前先测量高度，新版依赖预取提前测量。

## 三、性能

模拟器 iPhone 17 Pro，iOS 26.5，Debug，无并发负载，两引擎在独立测试进程中运行。单位 ms，P50 / P95。

| 场景 | 正文可见 Texture | 正文可见 TextKit | 最长帧 Texture | 最长帧 TextKit | 峰值 MiB Texture → TextKit |
|---|---:|---:|---:|---:|---|
| 含表格 1067087 | 61.7 / 77.5 | 45.5 / 78.0 | 33.4 / 50.0 | 32.9 / 33.4 | 150.7 → 124.8 |
| 短正文 1067504 | 55.5 / 61.0 | 43.9 / 58.2 | 33.3 / 44.6 | 32.2 / 33.0 | 120.2 → 124.5 |
| 图文长帖 832584 | 124.8 / 131.1 | 61.0 / 63.4 | 48.1 / 53.4 | 31.3 / 33.3 | 139.0 → 128.4 |
| 长列表 893437 | 92.3 / 95.5 | 47.0 / 61.1 | 50.0 / 66.7 | 31.7 / 33.3 | 150.3 → 128.2 |
| 第 2 页直达楼层 | 71.7 / 87.0 | 74.7 / 92.4 | 41.0 / 50.0 | 48.4 / 57.3 | 158.9 → 125.7 |
| 测评帖 | 830.2 / 841.3 | 64.0 / 75.5 | 31.8 / 33.4 | 31.2 / 35.6 | 171.1 → 175.5 |
| 测评帖缓存命中 | 103.8 / 109.5 | 57.4 / 58.8 | 32.5 / 33.4 | 31.3 / 33.3 | 120.5 → 125.5 |
| 返回已读帖子 | 433.0 / 433.2 | 433.1 / 433.3 | 16.7 / 17.5 | 16.7 / 16.8 | 124.8 → 126.8 |

新版正文可见普遍更快，图文和长列表快约一半，测评帖从 830 ms 降到 64 ms；最长帧多数场景稳定在 33 ms 内。唯一变差的是「第 2 页直达楼层」，P50 慢 3 ms、最长帧多约 7 ms，是后续可优化点。内存大部分场景更低，测评帖和短正文略高（≤ 5 MiB）。
