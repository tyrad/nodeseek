# 详情页改造前后全面对比（Texture → TextKit，2026-11-22）

对比对象是同一分支 `feat/better-list`（`95bc21b`）里的两套详情列表：改造前为 Texture（ASTableNode），改造后为 UICollectionView + TextKit，由 `postDetail.useTextKitList` 切换。两者共用控制器、解析器、分页请求和底部回复栏，差异集中在列表渲染与楼层交互。

## 结论

| 维度 | 结论 |
|---|---|
| 首屏与正文可读 | 新版普遍更快或持平；测评帖正文可读时间模拟器从 940 降到 84 ms，真机此前从 559 降到 33 ms。 |
| 内存 | 新版峰值更低：模拟器各场景低 1～43 MiB；真机此前低 25～31 MiB。 |
| 滚动流畅度 | 普通翻页往返持平（16.7 ms）。测评帖和图文主楼的最长帧在本次模拟器上**变差**，需真机 Release 复测。 |
| 测评报告图 | 首次生成两版相近（约 0.95 s，模拟器）；缓存命中新版慢 16 ms（模拟器）。真机此前优化后重开为 112 → 47 ms，需复测确认最近改动没有回退。 |
| UI 一致性 | 256 对楼层截图仅 38 对高度差 ≤ 1 pt，新版 214 对更矮，主要来自标题、段落留白和引用块。 |
| 功能完整度 | 新增正文选字、VoiceOver 楼层操作、系统动态字号、稳定分页；仍有约 15 处旧版能力缺失或行为不同，最要紧的是**同楼多图不能左右翻**和**测评标签内图片不按报告图处理**。 |

### 分页与回弹（新版专项，模拟器）

| 指标 | 改写前 TextKit | 当前 TextKit |
|---|---|---|
| 触发下一页请求时距页底 | 0.54 屏 | 1.92 屏 |
| 到旧页底后等待追加 | 150 ms | 0 ms |
| 手指拉过页底时收到下一页 | 列表立即增加 10 行，页底跳动 1000 pt | 等回弹结束再插入，阅读位置偏移 0 pt |
| 第一次请求超时后 | 同一次滑动内重复请求 | 等下一次拖动才重试 |

旧版 Texture 依赖 ASTableNode 的批量预取，没有做手指在页底时暂缓插入的处理。上述场景的逐步用例见[分页 E2E 文档](../testing/detail-textkit-pagination-e2e.md)。

## 二、UI 截图对照

47 组楼层加投票主楼；浅色和深色、应用默认和 +8 pt 字号、媒体占位和加载完成，共 256 对，1 px/pt。

| 指标 | 数值 |
|---|---|
| 高度差 ≤ 1 pt | 38 / 256 |
| 高度差 ≤ 5 pt | 131 / 256 |
| 高度差 ≤ 20 pt | 213 / 256 |
| 高度差中位数 | 5.0 pt（默认字号约 3.7 pt，+8 pt 字号约 10.3 pt） |
| 新版更矮 / 更高（超过 1 pt） | 214 / 4 |
| 最大差值 | 893437 主楼 +8 pt：2420 → 2049 pt（−371 pt） |

逐张人工对照，主要差异来源：

1. **标题上下留白更小**：832584 的「需要大家参与节点池建设」「加入方法」等标题，旧版上方约多一行空白，新版贴近上一段。这是 832584 主楼矮 170～333 pt 的主要原因。
2. **段落间距更紧**：1067515 #28 中空行分隔的两段，旧版留整行空白，新版只有约半行。
3. **引用块结构和颜色不同**：893437「补充说明」下，旧版是三个独立的引用框，框内标题用主文字色；新版合成一个框，框内标题沿用正文的绿色标题样式。
4. **回复楼层底栏少一个按钮**：旧版有点赞、鸡腿、反对、回复、引用五个图标；新版没有引用，引用挪进了长按菜单。
5. 段内行高、列表缩进和图片宽度基本一致；深色模式下两版都使用系统动态色。

### 新版新增

- **正文自由选字**：长按文字出现系统选区和拷贝菜单，长按空白或楼层号弹出楼层菜单。
- **VoiceOver 楼层操作**：菜单项同时注册为无障碍自定义操作，链接按片段朗读。
- **跟随系统动态字号**：通过 `UIFontMetrics` 缩放，同时保留应用内字号设置。
- **分页更稳**：提前两屏请求，手指在页底时暂缓插入，超时后不在同一次滑动里重复请求。
- **楼号更容易点中**：`#1` 这类短链接扩大了点击范围；引用定位优先选原始楼层而非置顶或热评副本。
- **首屏遮盖**：首屏排好再揭开骨架屏，避免开头跳动。

### 两版一致

主楼标题与阅读等级、作者栏、交易风险提示、受限 / 404 / 需登录页、楼层头部标签（楼主、禁言、热评）、点赞 / 鸡腿 / 反对、代码块（复制、横向滚动）、ANSI 终端报告、投票、动图离屏暂停、链接分流（站内帖、楼号、用户页、外链）、骨架屏、页码胶囊与跳页面板、「点击加载新评论」、中间页进入提示卡、深色模式。两版都没有剧透折叠、下拉刷新、向上翻页和滚动位置恢复。

## 四、实现与依赖

| 项 | Texture | TextKit |
|---|---|---|
| 列表 | ASTableNode，屏外节点预先布局 | UICollectionView 自适应行高，屏外先用估算高度 |
