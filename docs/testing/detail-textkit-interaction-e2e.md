# 新版详情页交互 E2E 用例

从仓库根目录运行，模式为 daily。用例只读公开帖子，不核对登录账号；启动参数临时启用 TextKit。判断全部基于控件标识、屏幕坐标、剪贴板和本机日志，不依赖模型。

| 编号 | 命令 | 数据 |
|---|---|---|
| 按钮上拖动 | `make e2e-case CASE=textkit-drag-on-button` | 公开帖 1067259 |
| 楼层菜单 | `make e2e-case CASE=textkit-floor-menu` | 公开帖 1067259，会写本机剪贴板 |
| 跨标签图集 | `make e2e-case CASE=textkit-gallery` | 公开测评帖 1067722 |
| 同楼图集 | `make e2e-case CASE=textkit-floor-gallery` | 公开帖 1072089，主楼三张配图 |
| 游客点赞收藏 | `SIMULATOR_ID=<游客设备> make e2e-case CASE=textkit-guest-reaction-login` | 公开帖 1067259，设备须未登录 |
| 链接颜色 | `make e2e-case CASE=textkit-link-color` | 公开帖 1071908，含表格链接 |

## 按钮上拖动

在屏幕中段找到一个「回复评论」按钮，从按钮中心按住 0.3 秒再上拉三成屏高。通过条件：可见楼层集合发生变化，且没有出现回复引用栏。去掉 `DetailCollectionView.touchesShouldCancel` 的处理后此用例失败。

## 楼层菜单

1. 选一条完整在屏内的回复，按住右上角楼层号附近 1.2 秒。菜单须含「复制正文」「只看 TA」；游客另有「投放鸡腿」。
2. 清空模拟器剪贴板，点「复制正文」，在复制面板确认，剪贴板须有内容。
3. 再次长按，点「只看 TA」。出现筛选条后，回复楼层里的作者须为同一人（主楼置顶，不计入）。点「查看全部」，筛选条消失。

## 跨标签图集

1. 等首栏终端报告生成截图，点放大按钮。日志 `打开详情大图: count=N` 中 N ≥ 2，即图集含所有标签的图。
2. 横向滑动一次，大图浏览器当前图片的地址须变化。
3. 单击关闭，报告图回到原处，纵坐标偏差不超过 1 pt。

## 同楼图集

1. 读到主楼第二张配图完整在屏内（每次滚动约一成屏高），点它。
2. 日志中 N ≥ 2；大图首张须是点中的那张，不能总从第一张开始。
3. 横向滑动翻到另一张；单击关闭后，点过的图回到原处，纵坐标偏差不超过 1 pt。

## 游客点赞收藏

未登录设备上分别点主楼「点赞」「收藏」，须直接进入登录页（`login-hint-container`），不弹确认框。若弹出「取消」确认框，说明设备已登录，用例直接报错。退回 2cd7998 的修复后此用例失败。

## 链接颜色

逐屏截图共 8 张，统计站点绿（15,128,85）与系统蓝像素。站点绿须超过 200 像素，只说明截到了链接（强调色标题也会计入）；真正的判据是没有一张截图出现超过 40 像素的系统蓝。给表格链接加回 `.link` 属性后，前三屏都出现系统蓝，用例失败。

样本帖子被删或改版时，失败信息会给出卡住的步骤，需另选含多张标签图的测评帖。
